# recipe system
система для управления рецептами и генерации списка покупок

# описание
проект является консольным приложением, котрое позволяет:
1) создавать ингредиенты с названием, количеством и единицами измерения веса
2) создавать рецепты блюд
3) менять количество
4) создавать диетические рецепты (веган, кето, без глютена и так далее)
5) создавать общий список покупок из рецептов

# установка

1) клонируйте репозиторий:
```bash
git clone https://github.com/drinkingpoet/recipe-system-HW2-.git
```
2) установите зависимости
```bash
pip install -r requirements.txt
```
3) запустите тесты 
```bash
pytest test_recipes.py -v
```
